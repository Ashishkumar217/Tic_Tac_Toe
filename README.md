# 🎮 Tic-Tac-Toe Game (Python Tkinter)

A simple and interactive **Tic-Tac-Toe** game built using **Python** and **Tkinter**. This desktop application allows two players to play the classic Tic-Tac-Toe game with a graphical user interface.

---

## 📌 Features

✅ Interactive GUI using Tkinter
✅ 3×3 game board
✅ Alternating turns between Player X and Player O
✅ Automatic winner detection
✅ Winning row/column/diagonal highlighted in green
✅ Pop-up message announcing the winner
✅ Displays current player's turn

## 🚀 Getting Started

### Prerequisites

Make sure Python is installed on your system.

Check installation:

```bash

```

---

### Run the Project

1. Clone the repository:

```bash
git clone https://github.com/Ashishkumar217/Tic_Tac_Toe.git
```

2. Navigate to the project folder:

```bash
cd Tic_Tac_Toe
```

3. Run the application:

```bash
python TicTacToeGame.py
```

---

## 🎯 How to Play

1. Player **X** starts the game.
2. Click on an empty cell to place your mark.
3. Players take turns alternately.
4. The first player to align three symbols horizontally, vertically, or diagonally wins.
5. The winning combination is highlighted in **green**.
6. A popup message announces the winner.

---

## 🧠 Winning Conditions

A player wins if they place three identical symbols in:

* Any row
* Any column
* Main diagonal
* Secondary diagonal

Examples:

```text
X | X | X
---------
  | O |
---------
O |   |
```

```text
X | O |
---------
  | X |
---------
O |   | X
```
